# 002 断点续算与内容指纹缓存

整批交换精确置换检验引入分块计算与跨运行沿用，启动时在 001 基础上补建。

- `runs.progress` 记录分块计算断点（批次统计、置换分布、逐批剔除中间状态），中断后按断点续算，完成后清空。
- `runs.dataset_checksum` 记录运行对应的数据指纹，写结果前校验，源数据更新后旧计算晚到也不并入新报告。
- `compute_cache` 按内容指纹缓存计算结果：`batch:<指纹>` 存单批四格统计，`dist:<指纹>` 存整批交换置换分布。内容不变则沿用，改动即换键重算；新报告只读取当前数据算出的键。

既有库由后端启动时的 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` 补齐新列，`compute_cache` 由 `create_all` 补建。
